CHAMFER DIRECTION RESEARCH PIPELINE

Purpose and status
This code separates correspondence quality, neural direction transfer, and step
acceptance in Chamfer-based registration. No candidate has passed all adoption
gates; Chamfer + Adam remains the baseline. The analytic examples establish
possible failure mechanisms, not a successful general registration method.
Six repeatedly examined development pairs contribute54 correlated endpoints.
They are not54 independent scenes or an untouched test set. All original
endpoints still admit additional Chamfer improvement under Adam continuation;
there is no demonstrated local-minimum escape. Lower Chamfer can raise GT error.

Data and baseline
Observed source X and target Y enter optimization. Evaluation GT gives the true
position of each source point. It never enters proposals, transfer, normalization
or finite acceptance. GT does enter offline research evaluation and adoption
screening, so these development pairs are not held-out validation.
4DMatch GT is reconstructed from flow, rotation and translation. The prepared
HF-derived3DMatch set uses real fragments with a controlled30-degree rotation
and translation of0.1 source radius; stored GT is the unperturbed source fragment,
not the official pose benchmark's ground truth. Preserve stored normalization.

The native loss is symmetric UNSQUARED Euclidean Chamfer:
 C(Z,Y)=mean_i min_j ||z_i-y_j||+mean_j min_i ||z_i-y_j||.
The baseline separately centers each cloud, samples at most2,000 points and uses
nine NDP levels, three hidden layers of width128, frequency start k0=-8,
axis-angle SE(3) motion, and per-level Adam with learning rate.01.
The historical fixed-budget loop performs50 updates and a fresh endpoint
calculation per level. It is a budget adaptation, not a full NDP reproduction.
The original loop permits500 iterations and early stopping; its small-change
counter accumulates15 events, which need not be consecutive. The stopping audit
separates that original loop, a full-ceiling loop with cached stage handoffs,
and500 fixed-budget updates with fresh handoffs. Instrumented original traces
must exactly reproduce uninstrumented references, excluding elapsed time.
Native parameters are float32; cloned direction calculations are float64.

Pipeline
 observed X,Y -> baseline NDP -> clone endpoint -> point field f
  -> parameter update delta -> observed motion normalization
  -> finite objective/linearization checks -> evaluation against GT.
Clones leave the original trajectory and Adam moments unchanged. Earlier probes
use levels0,4,8 and updates0,25,49. The current field/mechanism/joint studies
instead use all nine ORIGINAL stopping endpoints of each reused pair.

Correspondence
For a transport plan pi, define row mass r_i=sum_j pi_ij and force
 f_i=sum_j pi_ij(y_j-z_i).
The barycentric displacement f_i/r_i is distinct from that force. Zero-mass
rows have zero force. Transport uses half squared Euclidean costs, observed
geometric entropy scale epsilon, and relaxed marginal penalty tau=2epsilon.
Soft, semi-relaxed, unbalanced and balanced models are controls, not novel OT.
Actual transport residuals must pass; balanced --newton enables refinement.
FPFH controls use33-dimensional normalized descriptors of CURRENT observed
clouds: normals radius2h/max30 neighbors, features radius5h/max100 neighbors,
where h is pooled within-cloud mean nearest-neighbor spacing. The mixed cost
adds epsilon*0.5*||a_i-b_j||^2/.1^2. Feature-only matching removes spatial cost.
Descriptors and scales are frozen within a trial. Neither variant is full RobOT.
Other controls are native CD, saturating NN, centroid alignment and Gaussian MMD.
Saturating NN is not OAR; MMD fields are not the complete MMD-Reg method.

Transfer
With J=dZ/dtheta, GD uses delta=J^T f. Ordinary ridge solves
 min_delta .5||J delta-f||^2+.5gamma||delta||^2,
implemented as delta=J^T(JJ^T+gamma I)^(-1)f with JVP/VJP and CG.
Weighted displacement fitting instead solves
 (J^T R J+gamma I)delta=J^T f, R=diag(r_i I).
This is standard regularized weighted least squares. RobOT already includes
correspondence-weighted displacement fitting: https://arxiv.org/abs/2111.00648 .
Row mass is not assumed to be calibrated correspondence confidence.
Gamma is a fixed ratio of an eight-step seeded kernel power estimate. The
standard ratio is.01; weak-damping studies use.0001. Historical solver ceilings
are preserved; accurate field/joint controls allow2048 CG iterations and require
actual relative residual<=1e-8. No GT selects damping or a favorable state.
Raw fit residual, ray alignment, shrinkage and normalized error are different
quantities. Lower fit error does not establish task improvement or prove that
the remaining error lies outside the model's tangent range.

Motion and finite acceptance
Earlier budget/weighted/descriptor studies match the actual Adam output speed.
That normalization cannot move if Adam's speed is zero. The current field,
mechanism and joint studies instead normalize linearized RMS output motion to
observed within-cloud spacing h; a zero direction stays zero.
Each direction is tested at caps1/16,1/4,1 under raw, own-objective trust and
common-CD trust policies. Backtracking permits21 dyadic attempts, requires
Armijo decrease with coefficient.1 and relative output linearization error<=.1.
For transport, own-objective acceptance uses the frozen-plan change
 Q(d)-Q(0)=.5 sum_i r_i||d_i||^2-sum_i f_i dot d_i.
Other fields use their frozen-scale objectives. Actual nonlinear output is
always evaluated. Surrogate decrease does not guarantee CD or GT decrease.

Focused mechanism checks
transfer_mechanism.py separates damping from missing modes in a two-point
native-CD example. That example alone does not resolve correspondence ambiguity.
rigid_witness.py strengthens the construction: a centered scalene triangle has
unique rigid and balanced-OT correspondence, and centroid correction is zero.
For task E=||Z-G||^2/n, f=-grad C and correct h=(G-Z)/n, a COMMON symmetric PSD
transfer T obeys grad E dot(Tf)=2 grad C dot(Th). Thus task-harmful CD motion can
coexist with task-helpful global motion that a CD-decrease test rejects.
This is elementary symmetry algebra, not a new general optimization theorem.
The code evaluates all six assignments and actual equal-norm finite steps.
The constructed J is full rank; it is not asserted to be an observed NDP J.
Correct matching in this rigid example does not guarantee partial-overlap OT.

ndp_transfer_factorial.py compares CD/UOT at weak damping, using the preceding
exact-field standard-damping arm as control. GD/Adam and all original replays
must match exactly. Weak damping helps UOT descent counts but fails matched-CD
superiority; one state fails the existing absolute MSE identity tolerance.

pipeline/joint.py and ndp_joint_probe.py compare one versus four correspondence
updates inside the SAME fixed-J model. CD uses a touching quadratic upper bound
of native unsquared distance and rejects exact zero-distance singular weights.
UOT fixes entropy and marginal penalties from INITIAL geometry. All iterations
solve for a TOTAL delta from the original endpoint with fixed gamma. Both UOT
variants retain the INITIAL plan for finite acceptance. The report checks inner
majorizer/reassignment descent, exact controls and actual finite displacements.
All432 solves pass and no checked MM inequality fails, but both four-step
candidates fail adoption. Seven raw finite trials fail the absolute MSE identity
check; zero accepted controlled trials fail. The global numerical gate remains
failed. These negative outcomes are retained; neither candidate is deployed.

Evaluation and advancement
Reports verify complete grids, exact replay/control equality, solver residuals,
normalization, acceptance and the exact identity
 E(Z+d)-E(Z)=2<Z-G,d>/n+||d||^2/n.
The strict absolute1e-12 identity gate is retained even for large raw steps;
its failures are disclosed instead of silently relaxing the criterion.
Frozen screens compare task-descent gains/losses against GD/Adam and declared
matched controls at tangent and finite scales in BOTH data families. Rejected
or zero updates do not count as rescues. Counts and error magnitudes are reported
separately. Only passing candidates can advance to native full trajectories and
new independent scenes. No current candidate qualifies. Prior favorable
self-reviews do not establish independent acceptances or conference readiness.
The budget audit includes model setup, matching, transfer, normalization and
finite acceptance, excluding evaluation GT and file writing on both sides.
Adam continuation preserves moments and uses two measured timing repetitions.
Selectors receive only observed losses, slopes, residuals and acceptance flags;
retrospective library oracles use GT solely as non-deployable diagnostic bounds.
